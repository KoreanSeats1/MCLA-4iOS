# 1.0 release validation

Validation date: 2026-10-05. Marketing version **1.0**, build **2**, ARM64, iOS/iPadOS **18.0** minimum. The source commit and artifact hashes are recorded in the release manifest, avoiding a self-referential documentation hash.

## Build and source

- Regenerated the Xcode project from the tracked CMake version/build settings, retaining the configured device signing setup.
- Release device build succeeded.
- Signature and ARM64 architecture checks passed.
- Build inventory matched **603 native Metal title libraries**. The handwritten renderer entry point was linked; Vulkan, MoltenVK and generic GPU command-processor symbols were absent.
- Both tracked dependency patches passed reverse-apply checks against the local pinned dependency modifications. Dependency worktrees were preserved; private generated/game/capture inputs are excluded from the source commit.
- Version 1.0 incorporates the control-overhaul branch and current main documentation history.

## Regression checks

- **22 portable regression executables passed**, including captured map-border bounds, map/fill transform equality, invalid and unrelated HUD bounds, timing math, hitch guards, presentation, draw/constant/state reuse, invalidation, texture conversion, touch transitions and overlay classification.
- The separate shader-ABI corpus audit passed for **295 pixel shaders**, with **242** using c224..255. The ordinary portable run's ABI fixture test alone does not scan that corpus; the additional invocation supplies the real staged HLSL directory.
- Real Metal packed-color tests passed red/yellow/green/blue and alpha through the seed normalized, integer and both corrected post-tonemap glow paths.
- Real Metal texture-view tests passed the tiled/linear mapping cases for red, gold, green, blue and alpha.
- Source whitespace checks passed.

## IPA packaging

- Packaged from a copy of the signed device app; the installed/built app's signing identity was not stripped.
- The staged copy has no personal provisioning profile or personal signing entitlements and is ad-hoc signed for recipient re-signing.
- IPA ZIP integrity and version/build metadata checks passed.
- Original executable/archives/video files and private signing extensions were excluded.
- Retained upstream license texts, project license, credits and third-party notices are included under `OpenSourceNotices` (33 packaged files).
- `MCLA-4iOS-1.0.ipa`, `SHA256SUMS.txt` and `release-manifest.json` identify the artifact. The final manifest records the exact release source commit.

## Gameplay evidence and limits

- Earlier physical gameplay was exercised on iPhone Air and M5 iPad Pro. The user confirmed the continuous controls were solid.
- Live M5 pixel history established the two post-tonemap passes adding blue to a red signal. Updated gameplay showed red glow and warm headlights; the user confirmed lights seemed fixed.
- A fresh M5 frame showed a blue/purple La Brea street-name sign. Its source atlas is blue/purple, and original console references also show blue street-name signs. No forced green recolor was applied; green freeway boards are separate.
- The padded circle's exact bounds were captured in the diagnostic HUD trace. The corrected classifier uses the same minimap transform, and its regression passes. That code was installed on Air/M5 before release preparation; the final post-install alignment screenshot was pending.
- No matched original-game time/weather/view comparison proves pavement reflection parity. Existing road specular calculations and source inputs were observed; no artificial gold-reflection boost was shipped.

These checks validate the specific build, package and audited behavior. They do not establish every race/weather/menu effect, public signing-tool combination, older device, sustained thermal session or 60 FPS physics case. Known missing shaders, road/checkpoint/fade reports and new-game ride height remain documented in [Known Issues](../KNOWN_BUGS.md). A successful incremental build is not a clean-clone build-reproducibility claim.
