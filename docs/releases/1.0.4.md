# MCLA 4iOS 1.0.4 — Metal startup hotfix

Marketing version **1.0.4**, build **6**.

A reported startup log identified the actual failure: the FSR Metal library used a deployment target unsupported by the recipient’s OS. Renderer setup then returned **GPU setup failed**, shown by the launcher as **Xbox/AOT runtime setup failed**. The scripts had inherited iOS 27 from the development SDK, including for the title shader corpus.

- Compile and link offline FSR, title and optional SMAA libraries with an explicit **iOS 18.0 minimum**.
- Rebuild FSR and all **603 title Metal libraries** for this release.
- Include the target in title-shader cache stamps so incompatible cached binaries cannot survive this change.
- Check every packaged Metal library’s embedded AIR target against the app’s `MinimumOSVersion`. Refuse to package newer or unverifiable targets.
- Keep the **Export Logs** launcher button introduced in 1.0.3.

Download **MCLA-4iOS-1.0.4.ipa** and re-sign it with your own account. Keep the same signing account and bundle identifier to preserve app data. Original game files are not included. The Mac preparation app is unchanged and remains in the [1.0.2 release](https://github.com/KoreanSeats1/MCLA-4iOS/releases/tag/v1.0.2).

The corrected shader deployment metadata is checked statically and with compiler regressions. Confirmation on the reporting iPhone remains pending; this is not a claim of testing every supported OS/device combination. See [validation](1.0.4-validation.md).

If startup still fails, turn **Graphics → Retail Mode OFF**, close and reopen MCLA, reproduce the issue and tap **Export Logs**.
