# MCLA 4iOS 1.0.2 — Mac Game Prep and expanded game compatibility

October 8, 2026. Marketing version **1.0.2**, build **4**. **Windows coming soon.**

## Downloads

- **MCLA-4iOS-1.0.2.ipa** — iPhone/iPad release, iOS/iPadOS 18.0+, ARM64. Re-sign with your own Apple account before installation.
- **MCLA-Game-Prep-1.0.2-macOS.zip** — standalone preparation app, macOS 13+, Apple silicon and Intel, with a quick-start guide.
- **release-manifest.json** and **SHA256SUMS.txt** — artifact identity, compatibility and integrity information.

Original game files and personal signing profiles are not included. Use your own Xbox 360 Complete Edition game copy. The game-data preparation download is a Mac app; the IPA is the device app.

## All changes in this update

- Add **MCLA Game Prep**, a native Mac companion with a related disc/road/download icon and a main screen showing the expected Complete Edition, Xbox 360 platform and USA / NTSC-U region.
- Add a clearly marked cyan drag-and-drop area for one ISO, RAR, ZIP, 7z or extracted game folder. Click the area or **Choose Game…** to select or change the input; the app shows the selected path.
- Discover a single neighboring ISO automatically. Perform that directory scan in the background so macOS directory-access delays cannot freeze startup before the window appears.
- Read Xbox XDVDFS directly without mounting. Support game-partition images and common full raw-disc partition offsets. Detect PS3 ISO metadata and show a specific platform explanation.
- Unpack archives using macOS libarchive, or copy an extracted folder. Accept a direct game root or a single wrapped game folder. An archive containing an ISO must be unpacked first, then the ISO can be selected.
- Produce the complete, lowercase `MCLA_Game_Files` layout beside the selected input, including movies and other files. Add a preparation report, progress/cancel controls and **Show in Finder**.
- Preserve existing output folders. Stage work temporarily and remove unfinished extraction after errors or cancellation. Reject unsafe paths, links, special files, duplicate names, malformed disc directories and truncated payloads; check space while unpacking.
- Expand the compatibility manifest and command-line validator to accept the exact `0F1CB201` / `0.0.0.13` executable fingerprint alongside the `5940C9DB` / `0.0.0.8` baseline. The alternate copy's full program payload and loading configuration match the compiled iOS game code despite header differences.
- Reject unverified `default.xexp` title-update patches. No title update is required or applied for the supported copies.
- Package a fresh **1.0.2 / build 4** release IPA with the updated manifest. Add detailed preparation, compatibility, transfer and troubleshooting documentation and reproducible synthetic archive fixtures.

This update retains the 1.0.1 controls, icon, minimap corrections and CPU optimizations. It introduces no new gameplay, graphics or measured FPS improvement; existing [known issues](https://github.com/KoreanSeats1/MCLA-4iOS/blob/main/docs/KNOWN_BUGS.md) remain.

## How to use the Mac applet

1. Unzip **MCLA-Game-Prep-1.0.2-macOS.zip** and open **MCLA Game Prep.app**. It can sit beside the ISO or run from another location. No Homebrew, Python, extra extractor or internet connection is needed. The app is ad-hoc signed and not notarized; macOS may require **Open Anyway** in Privacy & Security.
2. Drag your Xbox 360 Complete Edition ISO, archive or extracted folder onto **Drop your game here**, or click **Choose Game…**. A PS3 copy is incompatible.
3. Click **Prepare Game Folder**. Wait for **MCLA_Game_Files is ready to copy**. If an output already exists, move it aside first. Use **Cancel** to stop or **Show in Finder** to locate the finished folder.
4. Install and re-sign the release IPA, open MCLA once, then close it before transfer. Copy the **entire** output folder to **Files → On My iPhone/iPad → MCLA → MCLA_Game_Files**. On Mac, use **Finder → device → Files → MCLA**. `default.xex` belongs directly inside that folder; do not add another `Documents` directory.
5. Wait for copying to finish, reopen MCLA and check for **READY TO DRIVE**.

Keep the same signing account and bundle identifier when updating; back up saves before deleting the app. Full instructions: [Game Prep guide](https://github.com/KoreanSeats1/MCLA-4iOS/blob/main/docs/GAME_PREP.md) and [installation guide](https://github.com/KoreanSeats1/MCLA-4iOS/blob/main/docs/INSTALLATION.md).

## Validation and limits

A real RAR containing an extracted Xbox 360 game folder completed through the Mac UI; all 12 output files matched an independent preparation byte for byte. The alternate executable's program payload is identical to the baseline. Audio/music archives and all six movies also match. The cache has the same 22,068 file entries and identical directory structure: 22,057 entries match, 11 differ, and the newer archive fixes three out-of-bounds entries in the older copy.

Synthetic checks cover raw-disc offsets, extraction bytes, supported input selection, PS3 detection, compatibility rejection, unsafe archive paths/links/collisions, cancellation and unverified update patches. The alternate copy is **expected compatible**, but physical iPhone/iPad gameplay with it remains untested. Arbitrary same-title executables or title updates are not automatically supported.
