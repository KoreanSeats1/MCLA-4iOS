# 1.0.3 release validation

Validation date: October 9, 2026. Marketing version **1.0.3**, build **5**.

- Regenerated the Xcode project and completed an ARM64 Release build for iOS/iPadOS 18.0+. The release app is ad-hoc signed for recipient re-signing.
- Strict signature and shader/backend validation passed: 603 title Metal libraries, handwritten renderer present, no Vulkan/MoltenVK/generic command-processor symbols.
- `python3 tools/test_mcla_log_archive.py` passed against the production ZIP exporter: ZIP CRC integrity, exact file bytes, nested and Unicode paths, multi-chunk files, rotated logs, empty files, no-diagnostics report export, game/save/cache exclusions, symlink exclusions and output errors.
- The isolated iPhone simulator preview showed Export Logs and Save Management fitting in portrait and landscape. This does not establish physical-device rendering or gameplay compatibility.
- A separate simulator integration linked the production launcher/controller/exporter to explicit runtime stubs. A synthetic startup failure cleared launch state, restored Export Logs, produced a ZIP with no detailed diagnostic files, and presented the real UIActivityViewController share sheet. Result: `MCLA_LOG_EXPORT_UI_TEST PASS`.
- Source packaging excludes original game content and personal provisioning/signing material. The release packager validates IPA ZIP integrity and produces SHA-256 checksums and a source-commit manifest.

Physical-device sharing, recipient signing configurations and the reported Xbox/AOT startup failure remain unverified. The update provides diagnostic retrieval, not a claimed fix for that failure. Existing detailed logs require Retail Mode off before the failing run; the export cannot reconstruct previously disabled logging.
