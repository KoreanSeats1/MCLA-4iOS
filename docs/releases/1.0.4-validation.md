# 1.0.4 release validation

Validation date: October 9, 2026. Marketing version **1.0.4**, build **6**, application minimum **iOS 18.0**.

## Reported failure and reproduction

The supplied runtime log initialized the function dispatcher, input, audio and game-folder mount, then failed while loading the FSR library with an unsupported deployment-target message. Renderer initialization returned `GPU setup failed`, surfaced as `Xbox/AOT runtime setup failed`.

Inspection of the previous 1.0.3 IPA confirmed its FSR AIR target was **iOS 27.0.0**. The new release gate rejects that exact library as newer than the app’s iOS 18 minimum. Title libraries had inherited the same SDK-default target, so the complete title corpus was rebuilt too.

## Build and deployment checks

- Added a shared `-mios-version-min=18.0` flag to both offline compilation and library linking for FSR, title and optional SMAA shaders.
- Recompiled all 603 title libraries and the FSR library. Recompiled the optional SMAA library as a separate tooling check; it is not included in the standard IPA.
- Validated embedded AIR targets in all 605 generated libraries: **iOS 18.0.0**.
- Regenerated Xcode and completed an ARM64 Release build for iOS/iPadOS 18.0+. Verified version 1.0.4, build 6 and MinimumOSVersion 18.0.
- The actual standard app contains **604 offline Metal libraries**: 603 title libraries plus FSR. All embedded targets are **iOS 18.0.0** and meet the app minimum.
- Strict ad-hoc signing and backend checks passed: handwritten Metal renderer present, 603 title libraries, no Vulkan/MoltenVK/generic command-processor symbols.
- Release packaging now runs the deployment gate before creating an IPA, excludes original-game and personal signing material, validates ZIP integrity and writes the source-commit manifest and SHA-256 checksums.

## Regression

`python3 tools/test_mcla_metal_targets.py` compiled real Metal libraries with the installed SDK. The explicit iOS 18 build was accepted. Omitting the target reproduced the SDK-default mismatch and was rejected by the app-level packaging gate. Newer and unverifiable target cases were rejected. Shader cache stamps now include the deployment policy; the complete corpus was regenerated rather than retaining old binaries.

## Limits

The reporting phone and other physical devices/OS combinations have not been retested with this hotfix. This validation establishes corrected shader deployment metadata, successful compilation and packaging, not confirmed gameplay on every supported OS. Export Logs remains available for recipient confirmation. No game data, archives, provisioning profiles or credentials were published.
