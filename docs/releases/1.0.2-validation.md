# 1.0.2 release validation

Validation date: October 8, 2026. Both products report **1.0.2**, build **4**. Artifact hashes and source commit are recorded in `release-manifest.json` and `SHA256SUMS.txt`.

## Device IPA

- Regenerated the Xcode project and completed an ARM64 Release build for iOS/iPadOS 18.0+. The public copy is ad-hoc signed for recipient re-signing.
- Verified strict code signing, all 603 offline native Metal title libraries and the handwritten renderer symbol. No Vulkan/MoltenVK/generic command processor symbols are present.
- Verified packaged version/build and the alternate executable profile in the embedded compatibility manifest.
- Packaging excludes original game files and personal provisioning/signing material and includes open-source notices. ZIP integrity and all release checksums passed.
- This update changes compatibility metadata and distribution tooling; the gameplay/runtime code remains the 1.0.1 implementation. No new physical-device gameplay or sustained-performance claim is made.

## Mac preparation app

- Built and ad-hoc signed a universal ARM64/x86_64 application for macOS 13+ with the generated icon and current compatibility manifest.
- Verified signatures, architectures, ZIP integrity, version/build and executable permissions in the ZIP. The download includes a quick-start file, full preparation/installation guides and the license.
- The native UI accepted the real RAR and completed preparation, displaying the ready-to-copy message. Its 12 output files matched an independent run of the preparation engine byte for byte.
- A launch stack sample identified synchronous neighboring-directory enumeration as a startup blocker. Enumeration now runs in the background after window creation; final launch and the visible drag-and-drop screen were verified.
- Core synthetic tests pass for file bytes, nesting/lowercase paths, existing-output preservation, cancellation, incompatible title/media/hash, malformed directory cycles, path traversal, out-of-bounds/truncated ISO extents and four raw-disc partition offsets.
- Input tests pass for ISO/RAR/ZIP/7z/folder selection and specific PS3 detection. Archive tests pass for wrapped ZIP layout, unsafe paths, links, duplicate paths, multiple game roots, truncated file payloads, unverified executable patches and cancellation cleanup. Fixtures contain no game content.

## Alternate game copy

- Xbox title ID `545407F8`, media ID `0F1CB201`, header version `0.0.0.13`, exact executable SHA-256 `6e78e00a84beee89aa23f4f3f5ed4ff7cc443e6efe356b50ec6ee8d29a8632c7`.
- Compared with the recorded `5940C9DB` / `0.0.0.8` executable, 365 header bytes differ. The entire program payload from offset `0x3000` is identical. Entry point, loading layout, encryption/compression settings, page descriptors, import library names/IDs and import record addresses match. The current loader does not reject the differing import-version metadata.
- Audio/music archives and six movies are byte-identical. `nxeart` differs. The cache retains 23,931 table entries, 22,068 files and identical directory structure; 22,057 file payloads/attributes match and 11 differ. All new file entries fit within the archive; three entries in the older copy extend past its end.
- The real package is an extracted Xbox game folder inside a RAR, not a raw ISO. Raw ISO handling was exercised using synthetic disc fixtures.
- No title update was included or applied. A local search found GTA IV updates but no MCLA update. Unknown `default.xexp` patches are rejected.

## Limits

Static executable/asset compatibility establishes that this alternate copy is expected to work with the compiled iOS code; it does not prove physical iPhone/iPad gameplay. Asset differences, existing rendering issues and broader device/thermal behavior remain unverified. The IPA requires recipient signing. The Mac app is not Developer ID signed or notarized. No Windows preparation binary is included; Windows is coming soon. This incremental build uses locally prepared generated code and shader inputs and does not establish a one-command clean-clone build.
