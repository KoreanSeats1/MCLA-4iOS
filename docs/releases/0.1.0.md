# MCLA 4iOS 0.1.0 — Initial public beta

An early iPhone/iPad adaptation of Midnight Club: Los Angeles — Complete Edition, built on LARecomp, ReXGlue and the isolated Theft4 Apple foundation.

[Gameplay showcase](https://youtu.be/zmHd-WfsaX4) · [Detailed installation and technical README](https://github.com/KoreanSeats1/MCLA-4iOS#readme) · [Credits](https://github.com/KoreanSeats1/MCLA-4iOS/blob/main/CREDITS.md)

## Included

- Ahead-of-time ARM64 game execution and a hand-written, title-specific Metal renderer.
- 603 offline native Metal shader libraries; production rendering does not use Vulkan/MoltenVK or the generic Xbox GPU command processor.
- Standard 30 FPS, plus **experimental native 60 FPS** using both real-delta timing paths, camera smoothing and chassis-depth corrections. No MetalFX frame generation.
- 720p/900p/1080p scene settings, optional FSR 1, texture filtering, bloom, motion-blur and DoF controls.
- Controller, touch/tilt, adjustable controls, save-management UI, Retail Mode and bounded diagnostics.
- Automatic packed-color, full-screen overlay and original-material-LOD behavior; the only experimental menu switch is 60 FPS.

## Download and install

Download **MCLA-4iOS-0.1.0.ipa**, sign it with your own account using Sideloadly or AltStore Classic, then provide your own extracted Xbox 360 Complete Edition files in `Documents/MCLA_Game_Files/`. **No game data is included.** The IPA contains no personal provisioning profile or signing identity and must be re-signed for your device. A checksum file is provided.

Initial gameplay testing covers iPhone Air and M5 iPad Pro. The build minimum is iOS/iPadOS 18.0; other devices are unverified. A demonstration of approximately 58 FPS is not a guarantee of locked 60 FPS in every scene or after throttling.

## Known bugs

**Blue distant light glows remain unresolved.** Two shader programs observed in the latest M5 run are not yet included: VS `D866F0D1394908B8` and PS `F1DAD9A46DA1A834`. Road flicker, checkpoint smoke/colors, full-screen fades, a new-game rear-wheel/ride-height report and video/60 FPS/thermal behavior still need broader regression testing. See the [full known-bugs list](https://github.com/KoreanSeats1/MCLA-4iOS/blob/main/docs/KNOWN_BUGS.md).
