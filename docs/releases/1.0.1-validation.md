# 1.0.1 release validation

Validation date: 2026-10-07. Marketing version **1.0.1**, build **3**, ARM64, iOS/iPadOS **18.0** minimum. Artifact hashes and the source commit are recorded in the release manifest.

## Regression checks

- All 24 portable C++ regression executables and the intro-hook wiring check passed.
- Coverage includes 360-heading minimap/GPS cases, active-stream differential transitions, exact constant snapshots and whole-buffer vertex conversion recipe equivalence.
- Both dependency patches pass reverse-apply checks against the pinned local checkouts; local dependency changes remain represented by tracked patches.

## Build and distribution

- Regenerated Xcode project and signed Release build succeeded.
- ARM64, marketing version 1.0.1 and build 3 verified.
- Strict code-signature verification passed; all 603 native Metal libraries are present. The handwritten renderer is linked, with no Vulkan/MoltenVK/generic command processor symbols.
- The supplied artwork was resized to a 1024×1024 opaque PNG for the iOS asset catalog; the README uses the same image. Ricioly is credited in README and CREDITS.
- CoreDevice confirmed successful installation on iPhone Air and M5 iPad Pro. iPhone Air launch succeeded. M5 automatic launch was blocked by its locked screen; installation succeeded.
- Signed executable SHA-256: `2a08157665118e780571b8d534b2dbc4e8758f1bc92149ed80640806caa056f9`.
- Public packaging uses a copy of the device app, removes personal provisioning, includes open-source notices and verifies ad-hoc signing and ZIP integrity. The manifest and SHA256SUMS identify the packaged artifact.

## Limits

Installation and automated checks do not establish visual title-logo acceptance, every race/weather/effect, sustained warmed-device frame budgets or a clean-clone build. Existing game-derived generated inputs were used. No measured sustained FPS gain is claimed.
