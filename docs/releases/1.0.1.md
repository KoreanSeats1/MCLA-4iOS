# MCLA 4iOS 1.0.1

Bugfix and CPU performance update, October 7, 2026. Marketing version **1.0.1**, build **3**.

- New app icon provided by **Ricioly**.
- Rotating minimap borders and GPS decorations receive the map's translation and scale, including mixed primitive batches.
- Hold a control and pinch anywhere to resize it; supported sizes range from 35% to 250% of the authored size, bounded by the screen.
- Skip Intro Videos defaults on. The startup hook preserves SWF construction and context before requesting the game's natural skip. The switch is available under Play Mode.
- Reuse converted geometry across shader/declaration combinations with identical ordered byte conversions.
- Prepare only shader-consumed vertex streams, refreshing deferred bindings when needed.
- Coalesce adjacent shader-constant snapshot ranges while preserving byte-exact comparisons.
- Resolve the embedded SDK version from its own checkout so app release tags do not break builds.

These changes reduce redundant CPU preparation. A matched warm-device comparison has not established a sustained FPS improvement. Title-logo visual acceptance, camera refocus-like blur, missing shaders, road/checkpoint/fade reports and new-game ride height remain open; see [Known Issues](../KNOWN_BUGS.md) and the [performance audit](../PERFORMANCE_AUDIT_2026-10-06.md).

Update with the same signing identity and bundle identifier to retain game data, saves and preferences. The public IPA contains no original game files or personal provisioning profile and must be re-signed by the recipient.
