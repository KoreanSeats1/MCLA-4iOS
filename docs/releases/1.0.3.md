# MCLA 4iOS 1.0.3 — Export Logs

Small diagnostic update, marketing version **1.0.3**, build **5**.

- Add **Export Logs** to the launcher. Save the ZIP to Files or share it through the iOS share sheet.
- Include existing runtime logs, runtime status/GPU text files, performance CSV/summary/pass captures, diagnostic text manifests and render/control reports. Include a current device, iOS, app version, settings and runtime failure report.
- Restore launcher controls after a startup failure so logs can be exported immediately. A new game session still requires reopening MCLA.
- Persist the small runtime status file even with Retail Mode on. Detailed runtime logging still requires **Graphics → Retail Mode OFF**, followed by reopening MCLA and reproducing the issue.
- Export uses streaming ZIP output. Game data, saves, caches, raw shader captures and symlinks are excluded.

Install **MCLA-4iOS-1.0.3.ipa** using your own signing account. Keep the same bundle identifier and signing account when updating. Original game files are not included.

This update adds diagnostics; it does not claim to fix the reported Xbox/AOT runtime startup failure. Synthetic failed-launch/export/share-sheet integration passed in the simulator; physical-device verification remains pending. See [validation](1.0.3-validation.md).

The Mac preparation app is unchanged; download it from the [1.0.2 release](https://github.com/KoreanSeats1/MCLA-4iOS/releases/tag/v1.0.2).
