# 0.1.0 release validation

Verified on 2026-10-05 before publication:

- Release device build completed successfully after portable include paths and signing templates were updated.
- Device app signature verification passed.
- All 21 portable regression executables passed, covering timing, presentation, draw/constant/state reuse, invalidation, resource lifetime, geometry and texture conversion, input and overlay classification.
- The separate shader ABI corpus audit passed for 262 pixel shaders; 221 use the high pixel-constant registers.
- Build inventory verified 603 title Metal libraries and the direct renderer entry point. Vulkan/MoltenVK/generic command processor symbols were absent.
- Both dependency patches matched the local modifications at the pinned revisions via reverse-apply checks.
- Public source selection contained no original game archives/executable, private provisioning, private keys, personal device identifiers or private home-directory paths. Upstream notice and patch whitespace is preserved.
- The IPA ZIP integrity check passed. Version 0.1.0/build 1 and ARM64 architecture were verified. Existing app icon is included.
- IPA staging used a copy of the device app; personal provisioning was removed and the copy was ad-hoc signed and verified. It has no personal signing entitlements.
- Thirty retained upstream license texts plus project license, contributor catalog and third-party notices are included in the IPA's OpenSourceNotices folder.
- Checksums and a public artifact manifest accompany the IPA.

This is packaging/regression evidence, not a promise of full game correctness. Earlier physical gameplay was exercised on iPhone Air and M5 iPad Pro; public sideloading tools, sustained thermal performance, all races and experimental 60 FPS physics are not comprehensively validated. See Known Bugs for outstanding rendering and suspension reports.
